How the model works

Task: binary classification. Will a drug pair have a clinically significant interaction (moderate or worse)?

Features (26): each pair becomes a vector of mechanistic features built from the two drug profiles. Examples: strong CYP inhibitor × substrate, both QT-prolonging, P-gp inhibitor × P-gp substrate, narrow therapeutic index involved, and the Jaccard similarity of the two profiles. Two more features feed in the rule engine's output (its highest severity and number of findings), which makes this a hybrid knowledge + ML model.

Labels (positive–unlabelled learning): positives are curated interactions plus any imported DrugBank/TWOSIDES pairs. Negatives are curated "no significant interaction" pairs plus randomly sampled unlabelled pairs, at 4 unlabelled pairs per positive. This is standard practice in DDI prediction because true negatives are rarely documented.

Algorithm: L2-regularised logistic regression with balanced class weights, trained by batch gradient descent in the browser. Evaluation uses a stratified 80/20 split plus 5-fold cross-validation, compared against a rules-only baseline.

Use: the model scores every pair, including pairs missing from the knowledge base, and explains each score by the features that contributed most.

Supported formats & current sources

Reference data checked against the publishers in November 2026. Versions move, so confirm before citing in your dissertation.

1. DrugBank — interaction table

Columns: drug1, drug2, severity, description, management (severity: contraindicated / major / moderate / minor).
Current: DrugBank 6.0 is the latest major release (Knox et al., Nucleic Acids Res 2024). It grew FDA-approved drugs from 2,646 to 4,563 and drug–drug interaction records from 365,984 to 1,413,413 — roughly a 300% increase over DrugBank 5.0, which earlier versions of this tool were built against. The downloadable XML is versioned separately; 5.1.21 was released on 2 June 2026. A free account and academic licence are required at go.drugbank.com.

2. TWOSIDES / nSIDES — pharmacovigilance signals

Columns: drug_1_concept_name, drug_2_concept_name, condition_concept_name, PRR.
Current: TWOSIDES covers over 3,300 drugs and roughly 63,000 drug combinations mined from FAERS, released under CC-BY 4.0. The nSIDES family has since grown to include OFFSIDES (438,801 off-label signals across 1,332 drugs), OnSIDES (2.7 million adverse reactions extracted from about 42,000 FDA labels using a ClinicalBERT model) and KidSIDES (paediatric signals). The lab has moved to Cedars-Sinai; downloads remain at nsides.io.

3. DDInter 2.0 — curated interactions with management

Import using the DrugBank column layout. DDInter 2.0 (Nucleic Acids Res 2025;53(D1):D1356) covers 2,310 drugs and 302,516 interaction records with 8,398 distinct pharmacist-reviewed mechanism descriptions and management recommendations, plus drug–food, drug–disease and therapeutic-duplication records. Free for academic use and a good complement to DrugBank for this project.

4. FDA — CYP and transporter tables

The FDA now publishes a clinician-facing companion to the developer table: Examples of Drugs that Interact with CYP Enzymes and Transporter Systems. It adds non-drug perpetrators — St John’s wort, curcumin, diosmin, tobacco smoke and grapefruit juice — and is the source used here for strong-versus-moderate inhibitor grading.

The full TWOSIDES file runs to tens of millions of rows, too large for a browser. Filter it first with the companion Python script (train_ddi_model.py) — for example to your study drugs, or PRR ≥ 2 with at least 10 reports — then import the reduced CSV here.

6 · VerdictHighest severity + evidence, mechanism, management, plus whole-regimen burden

Beyond the pair

Two risks are not pairwise. Patient context (age 65+, renal impairment, hepatic impairment) changes how much an existing interaction matters, so where a pair is already flagged the tool raises it one step and states the reason; it never manufactures an interaction from context alone, and never escalates to contraindicated, which is a labelling status rather than something a risk factor confers. Whole-regimen burden counts how many drugs in the list carry the same risk attribute — QT prolongation, bleeding, sedation, serotonergic activity, anticholinergic load, potassium retention, nephrotoxicity, narrow therapeutic index — because the classic triple whammy and anticholinergic burden scales are count-based risks that a pair-by-pair check cannot see.

Before you use this tool

MedSecure is an educational student project, not a medical device and not a clinical decision support system. It has not been validated for patient care.

  • It is incomplete. The knowledge base is a curated teaching subset of around 80 drugs. If it reports no interaction, that is not evidence the combination is safe.
  • It ignores the patient. It does not consider dose, route, duration, age, pregnancy, genotype, or kidney or liver function.
  • Part of it is a prediction. The machine-learning score is a statistical estimate, and pharmacovigilance signals show association, not causation.
  • It is not advice. Never start, stop or change any medicine based on this tool.

If you have a question about your own medicines, speak to a pharmacist or doctor. For clinical work, use a professional reference such as Stockley's, Lexicomp, Micromedex, the BNF or the National Formulary of India.
